# 首页技术栈卡片与案例轮播图片改版设计

## 目标

在不改变首页其他区域、导航和案例轮播交互的前提下，完成两项视觉更新：

1. 首页首屏右侧以 React 结构和 CSS 重构为参考图中的四层“智能软件栈”，不使用整张参考图替换。
2. 案例轮播左侧图片更新为三张统一风格的企业后台界面图：智能投标协作系统使用用户提供的原图，外贸获客工作台与企业知识和流程中心使用同一视觉语言生成的新图。

## 首页右侧结构

- 保留现有 `Hero` 组件和左右两栏首屏布局，只重构 `.hero-system` 内部。
- 卡片顶部居中显示 `INTELLIGENT SOFTWARE STACK`。
- 主体自上而下排列四层：业务场景、数据与规则、AI 能力、智能软件。
- 每层包含匹配语义的线性图标与中文标题，不显示现有步骤编号、说明文字和“运行中”状态。
- 四层之间使用中心竖线与圆形节点连接；左右各有一条带箭头的虚线回环，表达持续迭代。
- “数据与规则”使用青绿色描边；“智能软件”使用实心青绿色背景与白色内容；其余层使用浅蓝描边和深蓝内容。
- 底部独立分隔栏显示“从一个高价值环节开始 · 持续迭代”。
- 图标继续使用项目现有的线性 SVG 图标组件；整张卡片不使用图片或 Canvas。

## 响应式与动效

- 桌面端保持右侧卡片当前占位和约 4:5 的纵向视觉比例。
- 窄屏下卡片占满可用宽度，缩小内边距、字号和图标，但保留四层结构与中心连接关系。
- 两侧回环线在极窄屏下缩进或隐藏，避免挤压卡片内容。
- 仅保留轻微节点呼吸或连线流动效果，并遵守 `prefers-reduced-motion`。

## 案例轮播图片

- 智能投标协作系统：使用用户提供的截图作为案例主图，在不裁掉关键导航和数据区域的前提下适配现有图片框。
- 外贸获客工作台：生成浅色企业后台界面，延续参考图的顶部品牌栏、左侧导航、指标卡、线索/客户列表和流程进度模块；内容聚焦外贸线索、渠道、跟进与转化。
- 企业知识与流程中心：生成同一设计系统下的知识与流程后台，包含知识分类、文档状态、检索/问答概览和流程任务进度。
- 两张生成图与投标系统截图保持相同画幅、浅灰蓝背景、深蓝正文、蓝青状态色、细边框、低阴影和中文企业软件风格。
- 生成图作为本地静态资源纳入项目，不依赖远程 URL；案例轮播的数据和交互逻辑保持不变。

## 质量与验收

- 首屏右侧在常见桌面宽度下与参考图的层级、间距、颜色和连线关系一致。
- 三张案例图具有一致画幅和清晰度，切换时不发生布局跳动。
- 页面在桌面和移动宽度下无横向溢出，文字和关键图形不被裁切。
- 运行自动化结构测试、lint 和生产构建。
- 使用浏览器分别截取首屏和三张轮播状态，与参考图进行视觉检查；修复高优先级差异后再交付。

## 非目标

- 不新增页面、路由、后台接口或数据持久化。
- 不改变首页左侧文案、导航、轮播控件和案例详情文案。
- 不把首页右侧参考图直接作为位图展示。
